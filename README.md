# Star-Portal

This is a portal for my personal website, [adamjaffeback.com](https://adamjaffeback.com/), born out of my love for the stars.

The website was constructed with Bootstrap 3 and copious amounts of CSS. It's a fully static site (plain HTML/CSS/JS, no build step) hosted on GitHub Pages.

To preview locally, serve the directory with any static file server, e.g.:

```
npx serve .
```
